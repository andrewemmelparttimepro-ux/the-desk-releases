# The Desk for Windows

[Download The Desk](https://github.com/andrewemmelparttimepro-ux/the-desk-releases/releases/latest/download/The-Desk-Setup.exe)

Run the installer over your existing installation. Your Desk connection and drafts stay saved. Versions 0.1.4 and later offer future updates inside The Desk.

These are NDAI supervised preview releases. Windows publisher signing is not configured yet.

The installer contains no invitations, account tokens or customer data. Connect with the invitation from your Desk owner. Access to the appliance still uses your existing connection.

Release downloads and the update feed are hosted here. This is not the cOd source repository.
