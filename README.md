# The Desk

Open [The Desk on the web](https://app.thedeskagents.com). Nothing to install.

The Windows app is retired and no longer published. Existing Mac, iPhone and iPad apps remain supported; NDAI supplies native apps manually when needed.

This repository retains release files and update feeds for existing clients. It is not the cOd source repository. Existing release artifacts and saved sessions have not been removed.
